# Lia Pinto — Power Embodiment Mentor & Mastercoach

Landing page oficial de **Lia Pinto**, Mastercoach de bienestar y mentora de encarnación de poder (*Power Embodiment Mentor*) para líderes, coaches, terapeutas y madres al servicio de los demás.

> *"Tu poder personal es la energía que recuperas cuando dejas de abandonarte."*

---

## 🚀 Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion (`framer-motion` & `motion`)
- **Icons:** Lucide React (`lucide-react`)
- **Hosting Target:** Vercel

---

## 🛠️ Comandos Locales

### Instalación de dependencias
```bash
npm install
```

### Iniciar servidor de desarrollo
```bash
npm run dev
```

### Compilar para producción
```bash
npm run build
```

### Verificación de tipos TypeScript
```bash
npm run lint
```

---

## 🌐 Despliegue en Vercel

1. Importar el repositorio desde GitHub (`jozhmet-byte/lia-pinto`).
2. Configuración predeterminada:
   - **Framework Preset:** Vite
   - **Root Directory:** `./`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
3. El archivo `vercel.json` incluido gestiona automáticamente las reescrituras de rutas para Single Page Applications (SPA) y caché de recursos estáticos.
